## 🚀 Features

coZify is built with React, TypeScript, Tailwind CSS, Framer Motion, and Zustand to deliver a seamless, high-performance financial tracking experience.

- **Daily Budget Engine**: Circular burn-rate rings and instant top-ups to track your daily allowance.
- **Dynamic Transactions**: Comprehensive expense & income tracking with smart categorization, custom categories, and intuitive swipe gestures.
- **Multi-Account Support**: Switch between multiple saved profiles instantly on a single device without logging out.
- **Visual Analytics**: Interactive weekly and annual spending insights with dynamic category breakdown charts.
- **Wallet & Virtual Cards**: Manage your net worth, save custom credit/debit cards, and set visual savings goals.
- **Premium Design System**: 7 core theme paradigms, hardware-accelerated micro-motion, and local haptic feedback for a tactile experience.
- **Local-First & Secure**: 100% local storage via Zustand, with optional Firebase cloud sync and offline data portability.

## 🛠️ Quick Start

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

## 🔐 Privacy & Backup
All data is stored securely on your device by default. You can seamlessly export full JSON backups or authenticate with Google to sync to Firebase for cross-device access.
